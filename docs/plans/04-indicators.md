# План 4. Живые индикаторы

Шаг 4 — движение. Зависит от шага 1 (status-токены).

Ссылки: [общее](00-common.md) · [образец стиля](../oh-my-pi-output-style.md) · [join-таблица](../components-join.md).

Статус 2026-10-22: выполнен, 4 пары закрыты (коммиты см. в
[00-common.md](00-common.md)); тема покрывает 50 из 90 задач. Разведка по
бандлу 3.16.2 переписала гипотезы плана:

- чат-шиммер — это класс `animated-gradient-text` (текст, клипнутый в
  градиентную ленту 300%, цикл 4 с: 2 с пробег + 2 с покой), а не отдельный
  data-хук; он живёт на «Thinking…», маркере стримящегося хода, лейбле
  запроса разрешения, титулах workflow-карточек, строке статуса remote и
  kind-лейблах бегущих тул-карточек. Сток красит яркий текст тёмной
  наседкой — «пульсация яркости»; тема переворачивает картинку в kitt:
  ярлык покоится в dim, слева направо пробегает брендовая
  голова с коротким muted-хвостом. Хук для highspeed-варианта (шаг 6) —
  три переменные `--zskin-shimmer-*`;
- `data-zcode-chat-loading-animate` — входной фейд обёртки спиннера
  ChatLoading, сам спиннер — `.animate-spin` (покрыт блоком «session
  activity» из шага 3-эры; статусных вариантов у спиннера в сборке нет —
  их несут существующие статусные правила 2.12 и карточек);
- прогресс: слоты `[data-slot="progress"]` / `progress-indicator`,
  `data-state` = `loading | complete | indeterminate` (Radix). Дорожка
  `bg-muted` → `--color-background-alt`, fill `bg-primary` → brand,
  complete → success; `h-1` стока уже 4px. Сегментный вариант защищён
  гардом `:not([class~="bg-transparent"])`; свип-подсветка
  update-charge оставлена — это честная indeterminate-движуха;
- 4.4: `FlipMetricValue`/`SmoothMetricValue` в сборке нет (единственные
  `metric-row` в бандле — из встроенной типографской демки). Поверхности
  нет — записано как ограничение, правило не заводилось.

Ловушка приёмки: `background`-шорткат в правиле сбрасывает стоковый
`background-clip: text` (он раньше по каскаду) — ярлык превращается в
сплошной прямоугольник; поймал живой зонд, правила переведены на
лонгхенды (`background-image` + `background-clip`). Живая приёмка:
computed-стили и скриншоты обеих схем, `prefers-reduced-motion` — ровный
dim без замороженной головы, откат схемы и снятие пробников подтверждены;
на живой поверхности («Fetching output» бегущей карточки) kitt виден.
Числа: голова 5,8:1 (#fe8019 на #282828) и 5,4:1 (#af3a03 на креме);
fill прогресса на дорожке 5,2/3,1:1, complete 6,4/2,5:1 (светлый success —
только заливка, как у иконок 2.12).

### 4.1. Shimmer (пара 3)
`Shimmer`, `ChatLoading`, `MagicKeywordSpec`.
**Что.** Бегунок `kitt`: полоса от `#7c6f64` через `#928374` к `#fe8019`
(bold на кресте), скорость 30 клеток/с, хвост 7 — без «пульсации» яркости.
**Как.** `[data-zcode-chat-loading-animate]`, классы shimmer; `background:
linear-gradient(...)`, `background-clip: text`, `animation` с шагом ≈ 33ms;
цвета — токены dim/muted/brand.

### 4.2. Спиннер и загрузка (пара 4)
`Spinner`, `Loader`, `CancellableLoader`.
**Что.** Глиф brand, без glow; idle — `#928374`; успех/ошибка — status.
**Как.** `.animate-spin` (есть) — убрать `filter: drop-shadow`; добавить
статусные варианты.

### 4.3. Прогресс (пара 5)
`Progress`, `ProgressBar`.
**Что.** Дорожка `#32302f`, заполнение brand (или success для завершённого),
высота 4px, радиус 2px.
**Как.** `[data-slot="progress"]`; `--color-progress-surface*` (1.1);
убрать возможный градиент — плоская заливка.

### 4.4. Метрика (пара 6)
`FlipMetricValue`, `SmoothMetricValue`, `MetricRow`.
**Что.** Число — mono `#ebdbb2`, единица/подпись — `#928374`; анимация
смены без перелива цветов.
**Как.** Классы метрик; токены foreground.
