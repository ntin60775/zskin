### 7.1. Графики (пара 94)
`Chart`, `UsageHeatmap`, `CodingPlanUsageBarChart`.
**Что.** Серии — ramp `usage-chart-1…6` (синий→аква→зелёный→жёлтый→
фиолетовый), сетка/оси `#3c3836`, подписи `#928374`, фон прозрачный.
**Как.** Сначала проверить в живом клиенте, чем красится SVG: токены
`--color-usage-chart-*` или инлайн-цвета библиотеки. Если инлайн — `svg path
{ stroke: … }`/`fill` по сериям (гипотеза), иначе хватит токенов.
