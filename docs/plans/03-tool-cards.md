# План 3. Карточки инструментов

Шаг 3 — каркас и доменные карточки. Зависит от шага 1; дифф берёт
правила из 2.21, подсветка — из 2.8.

Статус 2026-10-21: не начат. Идёт после шага 2, волна 3 — 3.1 → 3.13
по порядку.

**Входящие пометки из ревью волны 2.** Три пункта закрыть внутри шага 3,
отдельных проверок не заводить.

1. **Чипы источников и подчёркивание (2.5 × 2.17).** Правило 2.5 красит
   каждую `a` внутри `[data-conversation-selectable]` и включает сплошное
   подчёркивание. Бейджи 2.17 перекрывают цвет, но не декорацию: если
   инлайн-цитата окажется ссылкой, чип получит аква-подчёркивание под
   приглушённой подписью. На волне 2 живых источников не было. В теме уже
   стоит страховка — `text-decoration-line: none` на бейдже и его потомках
   внутри транскрипта; проверить на первом живом рендере с цитатами.
2. **Объём правила 2.9.** `[data-row-id] [data-slot="tooltip-trigger"]`
   ловит все тултип-триггеры строки. Карточки инструментов принесут в строку
   собственные кнопки, и они молча унаследуют «тихие иконки». Решить
   осознанно: оставить как общий тон строки или сузить до тулбара действий
   (например, через `:has()` на его контейнер).
3. **Живая доводка семи поверхностей.** Дифф, терминал, цель, todo,
   источники, артефакт и ошибка (2.21, 2.19, 2.23, 2.22, 2.17, 2.18, 2.20)
   на момент своих коммитов не были смонтированы и проверены на
   синтетическом клоне разметки. Шаг 3 монтирует ровно эти поверхности —
   совместить живую проверку с ним и поправить правила по факту, отдельную
   волну не заводить.

### 3.1. Карточка субагента (пара 51)
`AgentToolCallBlock`, `ConversationAgentToolCallRow`.
**Что.** Как карточка 3.2: фазовая рамка, заголовок-intent, дерево
инструментов с `└─` и приглушёнными именами.
**Как.** Наследует стили 3.2; дерево — классы agent-tree (гипотеза).

### 3.2. Каркас карточки (пара 64)
`ToolCallBlock`, `ToolLayout`, `ToolCallBody`.
**Что.** Рамка 1px, радиус 6px; running — brand, success — `#3c3836`,
error — `#fb4934`, warning — `#fabd2f`; фон: running — прозрачный, success —
`#1d2021`, error — `#3c2021`; заголовок внутри рамки, подписи секций — над
секцией; статус-иконка и время (`283ms`) — `#7c6f64`.
**Как.** `[data-tool-name]` (подтверждён в DOM 3.16.2),
`[data-tool-status]` — бордер/фон по статусу (в перепись текущего вида
не попал — проверить на живом тул-колле); `ToolLayout` — заголовок;
врезание титула в линию — опция `position: relative` + лейбл с фоном
базы, включать после проверки (P2).

### 3.3. Прогресс вызова (пара 65)

**Что.** Спиннер brand на ходу, после успеха — точка `#b8bb26`, ошибка —

**Как.** `.animate-spin` уже перекрашен; убрать `filter: drop-shadow`;
статусные варианты — `[data-tool-status]`.
