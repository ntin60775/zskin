# zskin — entry point

Живые CSS-темы для официального десктоп-клиента ZCode: лоадер запускает
штатный бинарник с `--remote-debugging-port` и по CDP инжектит CSS в
рендерер. Файлы продукта не изменяются.

## Карта артефактов

| Путь | Что это |
|---|---|
| `loader/zskin.py` | лоадер (stdlib-only Python 3): `run` / `inject` / `list` |
| `themes/` | CSS-темы; `example.css` — placeholder для проверки пайплайна |
| `skills/zskin/SKILL.md` | скилл: как применять, ограничения, границы |
| `.zcode-plugin/plugin.json` | манифест ZCode-плагина |
| `deploy.json` | стратегия поставки в sot-zcode-marketplace (контракт v1) |

## Принципы (нарушать нельзя)

1. **Продукт не модифицируется.** Ни `/opt/ZCode/**`, ни что-либо ещё из
   установки ZCode. Только флаг запуска + CSS поверх DOM через CDP.
2. **Только презентационный слой.** Через CDP — исключительно DOM/CSS.
   Не трогать подтверждения операций, сеть, учёт квот, телеметрию.
3. **Селекторы — гипотезы.** DOM рендерера не публичный контракт; каждая
   тема проверяется в живом клиенте до коммита.
4. Это личный проект под собственный аккаунт Z.ai; не распространять
   сборки и не позиционировать как продукт Z.ai.

## Стиль

- Пользовательские артефакты (доки, коммиты, скиллы) — на русском; код и
  идентификаторы — английские; комментарии в коде — английские.
- Лоадер — stdlib-only Python 3, без зависимостей.
- Коммиты: conventional (`feat:`, `fix:`, `chore:`, `docs:`), push в `main`
  допустим (solo-репо).

## Статус

Инфраструктура поднята; задачи (темы, watch/hot-reload, обкатка селекторов)
нарезаются отдельно.
