# zskin

Живые CSS-темы для **официального** десктоп-клиента ZCode. Лоадер запускает
штатный бинарник с флагом `--remote-debugging-port` и по CDP вставляет вашу
CSS-тему как `<style>` в рендерер — на лету, без модификации файлов продукта.

ZCode — Electron; клиент и так поддерживает дебаг-порт, а плагинная система
ZCode интерфейс не кастомизирует (запрос на темизацию висит в
[zai-org/feedback#171](https://github.com/zai-org/feedback/issues/171), P2).
zskin закрывает нишу до появления штатной темизации.

С функциональными дырами UI подход тот же: недостающее поведение не
достраивается JS-инжектом поверх DOM — подаётся запрос апстриму и ждём.
Первый кейс: удаление задачи доступно только из архивного списка —
[zai-org/feedback#1039](https://github.com/zai-org/feedback/issues/1039).

## Быстрый старт

```bash
# запустить клиент и накатить тему
python3 loader/zskin.py run --theme themes/example.css

# повторный инжект в уже запущенный (лоадером) клиент
python3 loader/zskin.py inject --theme themes/example.css

# то же с силуэтом композера — второй файл дописывается к теме в один <style>
python3 loader/zskin.py inject --theme themes/gruvbox.css \
    --composer themes/composer/rail.css

# посмотреть цели CDP
python3 loader/zskin.py list
```

Переменные окружения: `ZSKIN_ZCODE_BIN` (по умолчанию `/opt/ZCode/zcode`),
`ZSKIN_PORT` (по умолчанию `9222`), `ZSKIN_COMPOSER` (силуэт композера по
умолчанию для `run`/`inject`; ярлык читает её же).

Силуэты композера (`themes/composer/`): перенос восьми форм поля ввода
oh-my-pi — `rule`, `rail`, `field`, `band`, `claude`, `pi`, `borderless`,
`box`. Файлы палитро-независимы и работают с любой темой поверх.

Цвета проектов: в группированном сайдбаре лоадер красит имя проекта и
иконку папки, от имени вниз идёт вертикальная рельса цвета проекта
(вместо стоковой рамки списка чатов). Берётся нативный цвет группы из
меню цвета; если не задан — оттенок считается из пути проекта (порт
`session-color.ts` oh-my-pi: безопасная дуга OKLCH, дистанция от палитры
gruvbox, WCAG-контраст на светлой схеме). Чаты без проекта не красятся.
`--watch` держит лоадер резидентом: новые проекты из UI красятся сами
(опрос 5 с), перезагрузка страницы подхватывается повторным инжектом;
ярлык уже запускает с `--watch`.

## Почему это законно

- Клиент не модифицируется: ни один байт `/opt/ZCode/**` не меняется.
- `--remote-debugging-port` — штатный механизм Electron; подключение по CDP —
  внешнее наблюдение/управление презентационным DOM.
- Авторизация, подписи запросов (`x-client-sig`/`x-client-pow`) и учёт квот
  не затрагиваются.
- Условия ZCode ToS запрещают обход «файлов ограничений безопасности» —
  CSS поверх DOM к ним не относится. Дискуссия в fora/issue: см. скилл
  `skills/zskin/SKILL.md`, раздел «Границы».

## Статус

**Инфраструктура.** Лоадер — рабочая минимальная реализация (stdlib-only
Python 3): `run` / `inject` / `list`. Дальнейшие задачи (темы, watch-режим,
 hot-reload при перезагрузке окна, подбор селекторов) будут нарезаны отдельно.

## Границы

- Только презентационный DOM. Через CDP не трогаем подтверждения операций,
  сеть, учётные механизмы, телеметрию — ни отключать, ни подменять.
- Селекторы тем — гипотезы: DOM рендерера не является публичным контрактом
  ZCode и меняется между версиями.
